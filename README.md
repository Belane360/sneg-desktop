# ❄ Снег 0.4.0

Снег поверх рабочего стола macOS / Windows: сугробы на окнах и у нижней рабочей границы, постоянные снежки, лопата, автоматический снегоуборщик, иней и звуковые сцены. Независимая реализация, не связана с Flake.

## Автообновление

Репозиторий: https://github.com/Belane360/sneg-desktop

Версии: https://github.com/Belane360/sneg-desktop/releases/latest

Установите `Снег.app` из версии 0.4.0 один раз. Затем приложение само проверяет GitHub через 5 секунд после запуска и каждые 6 часов. Кнопка **Проверить обновления** запускает проверку вручную. Если доступна новая версия, нажмите **Обновить до …**, подтвердите установку и дождитесь перезапуска. При отсутствии сети снег продолжает работать.

Код скачивается только из Releases этого репозитория по HTTPS. Проверяется SHA-256, допустимый состав ZIP, версия и совместимость зависимостей. Новый код проверяется отдельным Python-процессом до активации. Версии хранятся в `~/Library/Application Support/Sneg/updates/versions`; `active.json` переключается атомарно. Исходный `.app` не перезаписывается, права администратора не нужны. В случае Python-ошибки запуска новая версия отключается, ошибка сохраняется в `last-error.log`, запускается предыдущая версия. Аварийное завершение процесса вне Python этот механизм не обрабатывает.

Параметры погоды и уборки хранятся отдельно и сохраняются при обновлении. Крупное обновление зависимостей пока требует полной установки; установщики PyInstaller также обновляются через Releases вручную. Встроенная установка предназначена для Python-запускателя, который используется в текущем Mac-приложении.

Для публикации разработчиком: измените `sneg/__init__.py`, закоммитьте изменения, создайте тег `vX.Y.Z` и отправьте его в GitHub. Workflow **Publish update** выполнит тесты и опубликует Mac-архив, небольшой `Sneg-update.zip` и его контрольную сумму. `packaging/make_update.py` проверяет совпадение тега и версии. Workflow с полными установщиками оставлен для ручного запуска.

```sh
git add .
git commit -m "Describe the change"
git tag v0.4.1
git push origin main v0.4.1
```

## Обновление на Mac

Скачайте **Sneg-Mac-0.4.0.zip**. В меню старой версии выберите **Выйти**, замените прежний `Снег.app` новым и откройте его. Новый запускатель использует уже установленный `~/Library/Application Support/Sneg/runtime-v2`, повторная загрузка компонентов не нужна.

Для первого запуска на новом Mac нужны macOS 12+, Python 3.9–3.13 и интернет (около 450 МБ). Запускатель сам подготавливает окружение и открывает приложение. Это неподписанное bootstrap-приложение, а не автономная нотариализованная сборка. При сбое открывается папка с `launch.log`.

## Исправление 0.3.1

Убрана замкнутая рамка инея, проявлявшая прямоугольники невидимых служебных окон. Остались только короткие кристаллы непосредственно под накопившейся снежной шапкой.

## Изменения 0.3

- Отключена системная тень снегового слоя (`NoDropShadowWindowHint`), создававшая тёмные контуры вокруг снежинок, снега и прозрачных областей.
- Для macOS исключены системные владельцы окон, окна без признака `kCGWindowIsOnscreen`, прозрачные окна и узкие панели. Фильтрация применяется и к сугробам, и к инею. Эффекты обрезаются по доступной рабочей области сверху: строка меню остаётся чистой.
- Чтобы скатать шар, зажмите снег прямо на рабочем столе. В обычном режиме слой проверяет положение курсора и принимает ввод только над накопленным снегом и шарами; во время перетаскивания удерживает ввод до отпускания кнопки. На свободных участках мышь проходит к рабочим приложениям. Панель собственных настроек исключена из перехвата. Переключение занимает до одного кадра (~33 мс); на macOS нужно подтвердить переключение прозрачности ввода на реальном устройстве.
- Явные инструменты лопаты и снежка сохранены как дополнительный вариант.

## Изменения 0.2

- Окна Qt.Tool на macOS по умолчанию скрываются при деактивации приложения. Теперь на снеговом слое включён `WA_MacAlwaysShowToolWindow`. Скрытие панели не останавливает таймеры и не пересоздаёт мир. Изменение геометрии существующего экрана сохраняет его мир.
- Снежки больше не превращаются при ударе в насыпь и не исчезают по таймеру. Они ложатся на поверхности, катятся по склонам, поддерживают другие шары; можно снова взять готовый шар. При отмене взаимодействия удерживаемый шар возвращается в мир.
- Убран прежний предел высоты сугроба 48 px. Перераспределение снега формирует пологие склоны, избыток на кромках осыпается и оседает ниже. Масса при этом сохраняется, кроме медленного таяния — около 0.12% рыхлого снега в минуту.
- Контур снежной шапки сглажен кривыми; края обтекают углы, вместо вертикальных обрывов. Постепенно проявляется иней по видимым рамкам, перекрывающие окна маскируют его.
- Лопата перебрасывает снег в сторону движения. Для уборки зажмите левую кнопку мыши.
- Мини-снегоуборщик автоматически проезжает вдоль нижней рабочей границы. Собранный снег учитывается как вывезенный груз, после него остаётся наледь до 1.5 px. Он также убирает лежащие на пути нижние снежки.
- Интервалы уборки: 30 секунд, 1, 2, 5 или 10 минут. По умолчанию включено, 2 минуты. Интервал отсчитывается после окончания проезда; направление чередуется. Кнопка **Снегоуборщик** запускает внеочередную уборку. Отключение автоматического режима не отменяет уже начатый проезд.

## Управление

В обычном режиме клики проходят сквозь снег. В режиме лопаты или снежка слой принимает мышь на всём экране. **Esc** / «Закончить игру» в трее возвращает клики другим приложениям; есть автоматический выход через 60 секунд.

Снежок: нажмите на сугроб или готовый шар, прокатите по снегу, отпустите. Для броска отпускайте в движении; для установки подержите неподвижно. Шары можно складывать в горку или снеговика.

**Пауза** останавливает снег, уборку и звук. Настройки погоды, звука и автоматической уборки сохраняются. Закрытие панели при доступном трее оставляет снег включённым. Для завершения выберите **Выйти** в трее.

## Проверка

36 автоматических тестов (проверка загрузки и контрольных сумм обновлений, защита распаковки, переключение версий и возврат при ошибке запуска, а также включая фильтрацию macOS, лепку без выбора режима и отсутствие отрисовки в верхней панели): накопление и перенос снега; сохранение массы при осыпании и работе лопаты; устойчивые шары и их перенос вместе с окном; автоматический проезд, наледь и повторный запуск; отключение автоуборки; скрытие панели без сброса мира; macOS-флаг видимости; Esc и возврат шара; UI настроек и генерация WAV.

Тесты и отрисовка выполнялись в Linux. На настоящем Mac ещё нужно проверить фон после сворачивания / переключения приложений, несколько Spaces и fullscreen. Проверка Qt-флагов здесь не заменяет проверку оконного менеджера macOS. Windows-адаптер также требует проверки на целевой системе.

Физика двумерная и стилизованная: профиль сугроба задан сеткой высот, снежки — кругами. Геометрия окон задаётся прямоугольниками; реальные радиусы углов и системные виджеты не считываются. При изменении перекрытия или закрытии окна снег на исчезнувшей части кромки пока сбрасывается. При отключении монитора его мир удаляется. Полноэкранные защищённые окна / отдельные Spaces могут перекрывать снег.

## Разработка и сборка

```sh
python -m venv .venv
# macOS / Linux:
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python main.py
.venv/bin/python -m pytest -q
# Windows: вместо .venv/bin/python используйте .venv\Scripts\python.exe
```

`--preview` — только панель и демонстрационные окна. Linux поддерживает предпросмотр и нижний сугроб; границы сторонних Linux-окон не считываются. `--screenshot FILE` сохраняет только собственную панель.

`python packaging/make_mac_launcher.py` собирает упрощённый Mac-архив. `python packaging/build.py` на целевой ОС создаёт автономную сборку PyInstaller; на Mac также DMG. На Windows скомпилируйте `packaging/windows.iss` через Inno Setup 6. Workflow `.github/workflows/build.yml` собирает установщики на GitHub runners по ручному запуску или тегу `v*`; здесь workflow не запускался. Для публичного распространения нужны собственные сертификаты подписи и нотариализация Apple.

Приложение работает локально, не отправляет данные и не снимает изображение экрана. На Mac геометрия читается системным CoreGraphics C API без PyObjC, на Windows — Win32/DWM.
